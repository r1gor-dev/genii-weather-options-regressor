# [L] Прогнозирование погодных условий

Вам предоставлены два набора данных: stage_1_regression_train.csv и stage_1_regression_test_features.csv. stage_1_regression_test_features.csv будет использоваться для предсказания температуры и подготовки файла для финальной оценки.

    stage_1_regression_train.csv: содержит данные для обучения модели. Каждая строка представляет собой наблюдение о погодных условиях с целевой переменной target, которая указывает значение температуры.
    stage_1_regression_test_features.csv: содержит данные для тестирования модели, в которых необходимо предсказать значения целевой переменной. В тестовом наборе также есть поле index, которое не является признаком и предназначено только для идентификации записей в итоговом файле предсказаний.


Задача

    Разработка модели: Создайте модель машинного обучения с использованием библиотек классического машинного обучения (например, sklearn).
    Обучение модели: Обучите модель на данных из stage_1_regression_train.csv, используя переменную target как целевую.
    Предсказание целевой переменной: Используйте обученную модель для предсказания температуры target для данных из stage_1_regression_test_features.csv.
    Формирование файла предсказаний: Сохраните предсказания в файл stage_1_regression_test_target.csv в следующем формате:
    Файл должен содержать два столбца: index (значения индекса из stage_1_regression_test_features.csv) и target (предсказанные значения температуры для каждого дня).


Описание признаков

    relative_humidity_2m – влажность, выраженная в процентах.
    dew_point_2m – точка росы в градусах Цельсия.
    cloud_cover – облачность в процентах.
    wind_speed_10m – скорость ветра на высоте 10 метров.
    wind_direction_10m – направление ветра на высоте 10 метров.
    uv_index – индекс ультрафиолетового излучения.
    is_day – индикатор дневного времени (1 – день, 0 – ночь).
    sunshine_duration – продолжительность солнечного света.
    shortwave_radiation – уровень коротковолновой радиации.

Целевая переменная:

    target – целевая переменная, измеренная температура.

Критерии оценки
Результат будет оцениваться по метрике RMSE (среднеквадратичная ошибка) на скрытых тестовых данных.
Балл за задачу рассчитывается на основе метрики RMSE по следующей формуле:

score=max(0,min(100,10+100⋅0.65787−RMSE0.65787))

Таким образом:

    за значение метрики RMSE < 0.065787 будет начислено 100 баллов
    за решение, соответствующее уровню "baseline" (RMSE = 0.65787) будет начислено 10 баллов
    за значение метрики RMSE > 0.723657 будет начислено 0 баллов
    отрицательные баллы не начисляются
